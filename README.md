# nikita-nova-portfolio-2026

Сайт-портфолио Никиты Новы. Astro, статическая сборка, два языка (ру / en).

## Команды

```sh
npm install      # один раз
npm run dev      # локальный сервер с горячей перезагрузкой, http://localhost:4321
npm run build    # сборка в dist/
npm run preview  # посмотреть собранный dist/
```

## Структура

```
src/
  content/
    projects/<адрес>/   кейсы: index.md (ру) + en.md (en) + картинки. Как добавить — README в папке
    articles/<адрес>/   статьи, так же
  content.config.ts     какие поля бывают у кейса и статьи; опечатка в поле останавливает сборку
  pages/                адреса страниц: ру в корне, en в en/. Сами страницы — тонкие обёртки над views/
  views/                шаблоны страниц: список проектов, кейс, список статей, статья
  components/           хедер, футер, главная, карточка, сетка, фильтр, галерея
  layouts/              BaseLayout.astro — <head>, Open Graph, тема, хедер, футер
  lib/content.ts        выборка кейсов и статей с подстановкой перевода
  i18n/                 ui.ts — словари интерфейса, utils.ts — хелперы путей
  data/                 categories.ts — восемь категорий, projects.placeholder.ts — заглушки для пустой сетки
  styles/
    ids/                копия дизайн-системы IDS (MIT), правим под себя
    site.css            стили сайта поверх IDS
public/
  fonts/                запасной шрифт Inter
  video/                видео кейсов (в галерее указывается как /video/имя.mp4)
```

## Как устроен контент

Каждая запись — папка с `index.md` (данные между `---` сверху, русский текст ниже) и картинками рядом.
Английский текст — `en.md` в той же папке; без него английская страница покажет русский текст.
Имя папки — адрес: `commo/` → `/projects/commo/` и `/en/projects/commo/`.
Картинки кладутся в полном размере, уменьшенные AVIF-версии делаются при сборке.

Тёмная тема переключается в меню и запоминается в браузере; по умолчанию берётся системная.

Документы проекта: «Постановка задачи.md», «Роли.md».

## Публикация

Каждый пуш в `main` собирает сайт и выкладывает предпросмотр на GitHub Pages
(вкладка Actions в репозитории): https://novanikita.github.io/nikita-nova-portfolio-2026/

Предпросмотр закрыт от поисковиков. Боевой адрес — nikitanova.com, хостинг Beget, этот деплой ещё предстоит настроить.
