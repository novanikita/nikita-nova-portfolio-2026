**Постановка задачи**  
  
**Краткая постановка задачи**  
Мы делаем сайт-портфолио, для мультидисципинарного дизайнера.  
  
**Подробно, что надо сделать**  
Есть дизайнер Никита Нова, я занимаюсь дизайном с 2019 года. И за это время у меня накопилось много проектов. Около 100.  
  
Все мои проекты разные: брендинг, реклама, сайты, приложения, иллюстрации, мерч, упаковка, книги  
  
Есть старый сайт [nikitanova.com](http://nikitanova.com). Он кажется устаревшим, его никто давно не обновлял. Хочется новую красивую и современную систему для своего портфолио  
  
Кейсы собраны по папкам и в целом контент готов к публикации. Кроме кейсов ещё хочется добавить статьи и страницу обо мне. Сайт должен быть доступен на двух языках русский и английский  
  
**Критерии качества:**  
1 сайт легко загружается из разных стран  
2 сайт красивый и приятный в использовании  

**Принятые решения (28 октября 2026)**

Контент
- На сайт идут все ~100 проектов. Кейс = картинки, видео и текст.
- Поля кейса придумываем сами; рабочий минимум: название, год, клиент, категория, обложка, краткое описание, полный текст, галерея, ссылка на живой проект, флаг «на главной».
- У проекта ровно одна категория. Категории: брендинг, реклама, сайты, приложения, иллюстрации, мерч, упаковка, книги. На главной есть фильтр по категориям.
- Тексты кейсов — только на русском, английский перевод делает Клод. Перевод лежит в файлах рядом с русским, его можно править.
- Статьи — на двух языках, Никита готовит в удобном формате.
- Старый сайт nikitanova.com не используем ни как источник контента, ни как референс.

Структура
- Страницы: главная (индекс), проекты, заметки (статьи), обо мне. У каждого кейса своя страница.
- На главной: заглавный экран с представлением и фильтром проектов, сетка проектов.
- Контакты: компактный единый блок с соцсетями.

Технологии
- Astro, статическая сборка. Дизайн-система на старте — IDS (Intuition Design System, MIT), скопирована в проект в `src/styles/ids/` и правится под себя.
- Шрифт — Proto Grotesk (Production Type). Есть начертания Regular и Light в десктопной лицензии. Для публикации нужна веб-лицензия и woff2.
- Два языка: русский без префикса (`/`), английский под `/en/`.
- Контент добавляется так: Никита присылает материалы, Клод раскладывает их по шаблону в проект.
- Хостинг — Beget, домен nikitanova.com остаётся. Для скорости из других стран предложен Cloudflare перед Beget (ждёт решения).
- Нужны превью ссылок (Open Graph) и скрипт оптимизации фото в AVIF.

Процесс
- Дедлайна нет. Дизайн делаем сразу в браузере, без макетов. От Клода — техническая реализация и подсветка несостыковок, не дизайн-предложения.
- План: сначала главная страница, потом раскатываем решения на остальные.

**Сделано 28 октября 2026, второй заход**
- Тёмная тема: переключатель в меню, по умолчанию системная настройка.
- Модель данных кейсов и статей (`src/content.config.ts`), инструкции в README внутри папок контента.
- Страницы: список проектов с фильтром, страница кейса (мета, текст, галереи, следующий проект), список статей, страница статьи. Всё на двух языках.
- Превью ссылок: у кейса в Open Graph подставляется обложка.
- Главная показывает проекты с флагом `featured`; пока таких нет — все проекты.
- Первые семь кейсов: Никита принесла папки с картинками, тексты (ру и en) и порядок галерей взяты из репозитория nikitanova. Поля «клиент» заполнены только для Додо и Commo, «что сделано» пока пустое.
- Заметка «Красота» скопирована из того же репозитория как пример статьи.
- Предпросмотр публикуется на GitHub Pages при каждом пуше в main: https://novanikita.github.io/nikita-nova-portfolio-2026/ (закрыт от индексации). Домен nikitanova.com сейчас обслуживается GitHub Pages из репозитория nikitanova, боевой деплой на Beget ещё не настроен.
